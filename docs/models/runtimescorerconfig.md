# RuntimeScorerConfig

Hydrated scorer config used at runtime. Never persisted directly.

Produced by hydrate_scorer_config from a StoredScorerConfig + live DB rows.

## Example Usage

```typescript
import { RuntimeScorerConfig } from "galileo-generated/models";

let value: RuntimeScorerConfig = {
  id: "<value>",
  filters: null,
};
```
