# ValidateDecisionScorerDatasetRequest

Test a decision evaluator on dataset rows. The dataset fields select the rows.

dataset_id, dataset_version_index, limit and starting_token have the same meaning and defaults
as in the LLM dataset request. scoreable_node_types must be trace or llm.

## Example Usage

```typescript
import { ValidateDecisionScorerDatasetRequest } from "galileo-generated/models";

let value: ValidateDecisionScorerDatasetRequest = {
  datasetId: "<value>",
  modelName: "<value>",
  question: "<value>",
  scorerConfiguration: {
    outputType: "boolean_probability",
    scoreableNodeTypes: [],
  },
};
```
