# ValidateDecisionScorerLogRecordRequest

Test a decision evaluator on log records, before or after it is saved.

model_name, question and answer_options are at the top level, in place of the LLM prompt fields
(ERD S6). The other evaluator settings are in scorer_configuration, as in the LLM request.
The request also holds the query that selects the records.

## Example Usage

```typescript
import { ValidateDecisionScorerLogRecordRequest } from "galileo-generated/models";

let value: ValidateDecisionScorerLogRecordRequest = {
  logStreamId: "00000000-0000-0000-0000-000000000000",
  filters: [
    {
      columnId: "<id>",
      operator: "eq",
      value: "example input",
      caseSensitive: true,
      type: "text",
    },
  ],
  sort: {
    columnId: "<id>",
    ascending: false,
  },
  modelName: "<value>",
  question: "<value>",
  scorerConfiguration: {
    outputType: "boolean_probability",
    scoreableNodeTypes: [],
  },
};
```
